# Lakshana S — Engineering Portfolio

A responsive portfolio for Lakshana S, an Electronics and Communication Engineering student interested in VLSI design, embedded systems, and IoT. The site highlights her technical skills, academic projects, internship, education, and paper-presentation award.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Portfolio content

Personal and résumé content is maintained in `src/data/portfolioData.js`. The résumé PDF is served from `public/Lakshana_Resume.pdf` and linked from the hero and contact sections.

The main page sections are:

- Introduction and résumé download
- About, achievement, and languages
- Technical and professional skills
- Internship and education
- Academic projects
- Contact details

## Technology

React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.
